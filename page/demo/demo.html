Hi, I'm Mirza 👋

I built Skyborne to see what my Claude Code agents were actually doing: who's working, what tools they use, where the tokens go. It turned into a city.

This is a demo. It's playing back a recorded session. Nothing here is connected to your Claude Code. To watch your own agents live, install it from GitHub. It runs entirely on your computer.

It's early, so expect rough edges. If something breaks, open an issue. And if you like it, a star helps a lot.
