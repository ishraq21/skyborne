Hi, I'm Mirza,

I built Skyborne for LLM observability and agent tracing. I wanted to see what my Claude Code agents were really doing: which ones are working, stuck or waiting on me, every step they take and how long it takes, which tools and helpers they reach for, and where the tokens and cost go. It turned into a city.

This is a demo. It's playing back a recorded session. Nothing here is connected to your Claude Code. To watch your own agents live, install it from GitHub. It runs entirely on your computer.

It's early, so expect rough edges. If something breaks, open an issue. And if you like it, a star helps a lot.

Thank you for checking out Skyborne!
